# 🖥️ PC Health Check

A quick terminal overview of your computer's health — CPU, RAM, disks, battery and uptime in one color-coded table.

Green means fine, yellow means getting busy, red means time to take a look.

## Run it

```bash
pip install -r requirements.txt
python pc_health.py
```

Works on Windows, Linux and macOS.

## Built with

- [psutil](https://github.com/giampaolo/psutil) — reads system information
- [rich](https://github.com/Textualize/rich) — draws the table and colors
